=== 7. Бронювання місця з часом життя (аналог SET NX EX) ===
  user:1 бронює event:3|A|5|12 на 10 хв -> True
  user:2 бронює те саме місце -> False
  user:1 бронює event:3|A|5|13 на 1 с -> True
  Через 1,2 с user:2 бронює event:3|A|5|13 -> True
